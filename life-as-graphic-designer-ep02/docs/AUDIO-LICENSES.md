# Audio and font provenance

- `public/audio/ep02-voiceover.mp3`: user-supplied ElevenLabs narration, original bytes preserved. No dialogue has been synthesized or replaced by this project.
- `public/audio/music-original.wav` and the original click/pop/tick/typing/success/confused/impact/notification/whoosh WAV effects: original deterministic DSP compositions from EP01. Source synthesis is preserved in the adjacent EP01 `scripts/prepare-assets.py` in this same repository. No samples or commercial songs.
- EP02 scroll, browser-close, pencil, scratch, ending-sting, spiral-pulse and computer-ambience effects: synthesized offline by `scripts/prepare-episode-audio.py`, seeded NumPy sine/noise synthesis, 48kHz PCM. No external samples.
- Space Grotesk local font: SIL Open Font License, preserved next to the bundled WOFF2 as `public/fonts/OFL-SpaceGrotesk.txt`.

Audio assets and generated geometric poster studies were created for the user's series. The fictional IDEA/BOARD browser uses no downloaded Pinterest images or interface assets.
