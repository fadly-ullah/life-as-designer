# EP03 media provenance

- `public/audio/ep03-voiceover.mp3`: user-supplied ElevenLabs recording, original bytes preserved. This project generates no new dialogue.
- `public/audio/music-original.wav`: original 82 BPM deterministic DSP composition generated by `scripts/prepare-episode-audio.py`. No samples or commercial songs.
- EP03 `delete`, `color-pulse` and `romance-slip` effects: original sine/noise synthesis in that same script. `color-pulse` accelerates during experimentation.
- Remaining series click/pop/whoosh/success/confused/impact/ending effects: original procedural audio from EP01/EP02, with synthesis source preserved in the adjacent projects in this repository. No commercial recordings.
- Space Grotesk: original local variable font, SIL Open Font License retained as `public/fonts/OFL-SpaceGrotesk.txt`.
- Great Vibes: Robert E. Leuschke / TypeSETit, SIL Open Font License retained as `public/fonts/OFL-GreatVibes.txt`, bundled from `@fontsource/great-vibes@5.3.0`. Used only in the fictional font selector and typography mistake, never for the series' editorial text.

All poster artwork is procedural SVG/CSS and contains no stock photos or external copyrighted reference images.
